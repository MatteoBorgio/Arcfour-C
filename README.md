## 📝 Description

A lightweight, dependency-free C library implementing the Arcfour (Alleged RC4) stream cipher algorithm. Created for educational purposes.

## ⚡ Quick Start

```bash

# 1. Clone the repository
git clone https://github.com/MatteoBorgio/Arcfour-C.git

# See the Development Setup section below
```

## 🚀 Available Scripts

- **all** — `make all`
- **arcfour** — `make arcfour`
- **example** — `make example`
- **clean** — `make clean`
